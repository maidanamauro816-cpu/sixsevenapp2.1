# SixSeven 2.1

Aplicación de comunicación original, independiente y en desarrollo. Este proyecto toma como referencia funciones generales de las apps de mensajería (chats, contactos, llamadas y personalización), sin copiar código, recursos, marcas ni interfaz propietaria de terceros.

## Estado
- Prototipo visual original en React + Vite.
- Preparación para Android con Capacitor.
- La mensajería real, contactos sincronizados, llamadas y notificaciones requieren configurar un backend y credenciales propios.
- El workflow de GitHub Actions intentará generar un APK de depuración para pruebas.

## Desarrollo
```bash
npm install
npm run dev
```

## APK de prueba
En GitHub, abrir **Actions** y seleccionar el workflow **Build SixSeven Android APK**. Cuando finalice correctamente, descargar el artefacto `SixSeven-Android-APK`.

## Privacidad y propiedad intelectual
SixSeven es un proyecto independiente, no afiliado ni respaldado por WhatsApp ni Meta. No debe usarse para acceder a servicios de terceros de forma no autorizada.
